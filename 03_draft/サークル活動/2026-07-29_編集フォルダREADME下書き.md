# 📌 03_編集 フォルダの使い方

このフォルダは「侍ラジオ」と「ライブ映像」の編集データを管理する場所です。

## 侍ラジオ

- `第n回_構成テンプレート`をコピーして、新しい回のフォルダを作ってください
- コピー方法：**Google Drive for デスクトップ**（PCにインストールした同期アプリ）でエクスプローラー上からコピー＆ペーストしてください
  - Web版のDrive画面では、フォルダは「コピーを作成」で複製できません（ファイルのみ対応）
- コピーしたら、フォルダ名の「n」を実際の回数に変えてリネームしてください（例：`第12回`）
- 中の3つのフォルダ名・番号（`01_元素材`／`02_完成データ`／`03_サムネ`）は変更しないでください（並び順が崩れてしまいます）

## ライブ映像

- `資料`フォルダ：編集マニュアルなど、編集作業に必要な資料を置いています
- `学内ライブ_構成テンプレート`をコピーして、新しいライブの回を作成してください（侍ラジオと同じ手順）
- 「年度フォルダ（例：`2026年度`）→ 月ライブフォルダ」の順で格納します
- 月ライブのフォルダ名は「〇月ライブ「サブタイトル」」の形式で統一してください（例：`8月ライブ「8回裏から本気出す」`）
  - `03_写真`のイベントフォルダ名も同じ名前で揃えると、あとで探しやすくなります
- 中の3つのフォルダ（`01_撮影素材`／`02_完成データ`／`03_サムネ`）の名前・番号も変更しないでください

## 困ったときは

テンプレートの使い方やコピーの仕方がわからない場合は、役員（幹部）まで聞いてください。
