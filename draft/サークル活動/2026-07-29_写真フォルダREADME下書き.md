# 📌 04_写真 フォルダの使い方

写真は「年度 → イベント」の2段階で整理しています。

## 使い方

1. 該当する年度フォルダ（例：`2026`）を開いてください
2. その中に、イベントごとのフォルダを作成してください（例：`8月ライブ「8回裏から本気出す」`）
   - 名前は`03_編集/ライブ映像`のフォルダ名と揃えると、あとで探しやすくなります
3. 年度フォルダが無ければ、新しく作ってもらってOKです
4. イベントフォルダがすでにあれば、そこに写真を追加してください

## ちょっとしたお願い

- 細かく分類しすぎず「イベント単位」でまとめてください
- ファイル名は「日付_内容」など、あとで見てわかる名前がおすすめです

## 困ったときは

分類に迷ったら、LIBRARY直下の「未分類」フォルダに入れてください。役員（幹部）が整理します。
