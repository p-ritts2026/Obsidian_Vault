# 📌 04_ネタ見せちゃん フォルダの使い方

このフォルダは、ネタ見せ開催時に使う「ネタ見せちゃんフォーム作成ツール」で集めた感想・アドバイスの回答データを保管する場所です。

## ① フォームを作る

1. 「ネタ見せちゃん フォーム作成」ツール（Google Apps Script）を開く
2. 開催日・説明文・出演者リスト（名前＋YouTubeリンク）を入力
3. 作成すると、出演者ごとに「動画＋感想・アドバイス記入欄」が並んだGoogleフォームが自動でできあがります
4. できたフォームのURLを、ライブの参加者・観客に共有して回答を集めてください

## ② 回答をこのフォルダに保存する

1. Googleフォームの「回答」タブを開く
2. 緑のスプレッドシートアイコン（回答をスプレッドシートにリンク）をクリックし、新しいスプレッドシートを作成
3. できたスプレッドシートの共有設定を**「閲覧者」**に変更する
   - 感想・アドバイスのデータは、誰かが誤って編集・削除してしまわないよう、閲覧のみにしています
4. そのスプレッドシートを、このフォルダ内の「〇〇年度」フォルダに移動する
5. ファイル名は「〇月〇日 ネタ見せちゃん（回答）」の形式で統一してください（例：`7 24 ネタ見せちゃん（回答）.gsheet`）

## 困ったときは

ツールの使い方や共有設定の変え方がわからない場合は、役員（幹部）まで気軽に聞いてください。
