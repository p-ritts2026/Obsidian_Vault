*(ツール使用: view, bash_tool, create_file, present_files)*

Form内容を見ると、構造は驚くほど単純でした。

- タイトル：「日付 ＋ ネタ見せちゃん」
- 説明文：ライブ回ごとの一言（ほぼ固定フォーマット）
- 「出演者名（YouTubeリンク付き）＋ 感想記入欄」が、出演組数だけ繰り返されている

つまり毎回の手間は、**13組分の名前を入力 → 1組ずつリンクを貼る**という地味な繰り返し作業のはずです。Googleフォームの作成自体をAPIで自動化するのは認証なども絡んで重くなるので、いただいた回答の通り「**コピペするだけで済む文章・パーツを自動生成するツール**」として設計します。

## 構成案

**入力部分**
- 開催日・ライブ名（タイトル用）
- 説明文（テンプレート入りで編集可、🔥や絵文字もそのまま）
- 出演者リスト：名前とYouTubeリンクをペアで入力
  - 1件ずつ追加もできるし、`名前　URL` を改行区切りで貼ると一括登録できるようにします（スプレッドシートからのコピペにも対応）

**出力部分**
- タイトル・説明文：そのままコピーしてGoogleフォームに貼るだけ
- 各出演者名：**リンク付きのテキストとしてコピー**できるボタンを用意します。Googleフォームの質問タイトル欄はリッチテキスト対応なので、これを貼るだけでハイパーリンクごと反映されます（今まで1件ずつ「リンクを挿入」操作していた手間がなくなります）

**地味だけど効く工夫**
- 前回入力した出演者リストをブラウザ内に保存しておき、次回開いたときに呼び出せるようにします（名前が変わらないメンバーが多い場合、微修正だけで済みます）

では実際に動くツールを作ります。

設計を少し練ります（ネタ見せという題材に合わせたトーン・色味にしたいので）。

**トークン設計**
- カラー：舞台の暗がり×スポットライトをイメージ。`#16151A`（暗幕の黒）、`#F5EFE6`（紙のような生成り）、`#FFC857`（スポットライトの黄）、`#E85D4C`（差し色の朱赤）、`#8A8678`（補助グレー）
- タイプ：見出しは少し癖のある明朝（"Shippori Mincho"）で寄席のめくり感、本文は読みやすいゴシック（"Zen Kaku Gothic New"）
- レイアウト：フォームをそのまま再現するのではなく、「めくり（寄席の名前札）」のメタファーでリスト化。1組＝1枚の札
- シグネチャ：出演者名をコピーすると、紙吹雪っぽい一瞬のフィードバックではなく、控えめに「コピー済み」の札がめくれる程度の小さな動き

function parseBulk(text){

      const name = (parts[0]||'').trim();
      const url = (parts[1]||'').trim();
      return newRow(name, url);
    })
    .filter(p => p.name);
}

/**
 * ネタ見せちゃん フォーム自動作成
 * ------------------------------------------------------
 * Webアプリとして開いたときの入口
 */
function doGet() {
  return HtmlService.createHtmlOutputFromFile('index')
    .setTitle('ネタ見せちゃん フォーム作成')
    .addMetaTag('viewport', 'width=device-width, initial-scale=1')
    .setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL);
}

/**
 * 前回入力した出演者リストを取得する（自分のGoogleアカウントごとに保存される）
 */
function loadLastPerformers() {
  const props = PropertiesService.getUserProperties();
  const raw = props.getProperty('NETAMISE_LAST_PERFORMERS');
  if (!raw) return [];
  try {
    return JSON.parse(raw);
  } catch (e) {
    return [];
  }
}

/**
 * 出演者リストを保存する
 */
function saveLastPerformers_(performers) {
  const props = PropertiesService.getUserProperties();
  props.setProperty('NETAMISE_LAST_PERFORMERS', JSON.stringify(performers));
}

/**
 * メイン処理：フォームを実際に作成する
 * payload = { title: string, description: string, performers: [{name, url}] }
 * 戻り値 = { editUrl, viewUrl, title }
 */
function createNetamiseForm(payload) {
  const title = (payload && payload.title || '').trim();
  const description = (payload && payload.description || '').trim();
  const performers = (payload && payload.performers || []).filter(function (p) {
    return p && p.name && p.name.trim();
  });

  if (!title) {
    throw new Error('フォームのタイトルが空です。開催日を入力してください。');
  }
  if (performers.length === 0) {
    throw new Error('出演者が1組も入力されていません。');
  }

  // 1. フォーム本体を作成
  const form = FormApp.create(title);
  form.setDescription(description);
  form.setCollectEmail(false);
  form.setRequireLogin(false);

  // 2. 出演者ごとに「動画（名前つき）」＋「感想欄」を追加
  performers.forEach(function (p) {
    const name = p.name.trim();
    const url = (p.url || '').trim();

    if (url) {
      try {
        const videoItem = form.addVideoItem();
        videoItem.setTitle(name);
        videoItem.setVideoUrl(url);
      } catch (e) {
        // URLがYouTubeとして認識できない等の場合は、見出しだけ入れて続行する
        form.addSectionHeaderItem().setTitle(name + '（動画リンクを認識できませんでした：' + url + '）');
      }
    } else {
      form.addSectionHeaderItem().setTitle(name);
    }

    form.addParagraphTextItem()
      .setTitle('感想・アドバイスをどうぞ')
      .setHelpText('一言だけでも大歓迎です！')
      .setRequired(false);
  });

  // 3. 次回のために出演者リストを保存
  saveLastPerformers_(performers);

  return {
    editUrl: form.getEditUrl(),
    viewUrl: form.getPublishedUrl(),
    title: title
  };
}

## 変更点

開催日を入力すると、説明文の「○月ライブのネタ見せ」の月部分が、**開催日の翌月**に自動で置き換わるようにしました。

- 例：開催日`7/20` → 説明文は「🔥**8月**ライブのネタ見せ🔥」
- 例：開催日`12/25` → 説明文は「🔥**1月**ライブのネタ見せ🔥」（年をまたぐ場合も正しく1月に戻ります）
