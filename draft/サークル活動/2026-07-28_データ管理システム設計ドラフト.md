# サークルデータ管理システム 設計ドラフト

座長OK後の本作業として、③〜⑦を先行してドラフト化。①②は性質上、パスワード等を扱うためユーザー自身の作業となる。

## ①②：Googleアカウント・ドライブ準備（要ユーザー作業チェックリスト）

- [x] アカウント名を決定：`pritts.official@gmail.com`
- [x] パスワードを決定（内容はメモに残さず、紙で厳重保管する運用）
- [x] パスワードを紙に控え、鍵のかかる場所（部室のキャビネット・金庫等）に保管
  - 見た人にすぐパスワードとわからない書き方にする
  - 保管場所を知るのは現役員のみに限定し、代替わりごとに更新
- [x] 二段階認証を設定し、バックアップコードの保管場所を決める（パスワードと同じ紙 or 別の安全な場所）
- [x] 管理者情報（アカウント名・緊急連絡先）を控える場所を決める（オフライン or 限定共有ドキュメント）
- [x] 新アカウントでGoogleドライブにログインし、マイドライブ直下に下記③の構成を作成

## ③：フォルダ構成設計（案）

ノート記載の例を基に、並び順・管理しやすさを考慮して番号prefixを追加。

```
00_運営
  ├─ 総会資料
  └─ 規約・引き継ぎ
01_マニュアル
  ├─ スタッフ向け
  │   ├─ 進行マニュアル
  │   └─ 運営マニュアル　　←役員のみ操作・編集可
  └─ 演者向け
      ├─ 台本の使い方
      ├─ 台本の作り方
      ├─ プロジェクター使用マニュアル
      └─ 道具出し資料（スタッフへの引き渡し用お手本）
02_広報
  ├─ SNS投稿素材
  └─ チラシ
03_編集
  ├─ 侍ラジオ
  │   └─ 第[N]回
  │       ├─ 元素材
  │       ├─ 完成データ
  │       └─ サムネ
  └─ ライブ映像
      ├─ 資料
      │   └─ 編集マニュアル
      └─ [年度]年度
          └─ [月]月ライブ
              ├─ 撮影素材（カメラの生データ＋その他素材）
              ├─ 完成データ
              └─ サムネ
04_会計　　←役員のみ操作・編集可
  ├─ 予算・決算
  └─ 領収書
05_写真
  └─ イベント別
06_デザイン
  ├─ ロゴ・素材
  └─ ポスター
07_年度別アーカイブ
  └─ 20XX年度
```

- 並び順：運営 → マニュアル（全員共有）→ 広報 → 編集 → 会計 → 写真 → デザイン → 年度別アーカイブ
- 「動画」フォルダは廃止し、03_編集の中の「ライブ映像」に統合
- 03_編集は「侍ラジオ」「ライブ映像」の2本立て
  - 侍ラジオ：第N回ごとに元素材・完成データ・サムネ（確定）
  - ライブ映像：年度→月ライブごとに撮影素材・完成データ・サムネ
- 番号prefixは並び替え目的。不要であれば外す。

## ④：共有ルール設計（案）

| 区分 | 対象フォルダ |
|---|---|
| 全員が閲覧・ダウンロード・編集可 | 上記以外すべて（01_マニュアル内の演者向け・進行マニュアル、02_広報、03_編集、05_写真、06_デザイン、07_年度別アーカイブ 等） |
| 役員のみ操作・編集可 | 00_運営（フォルダ全体）、01_マニュアル内の「運営マニュアル」、04_会計 |

- 基本方針は「全員が自由に見る・落とす・編集できる」オープン運用。役員のみ制限をかけるのは上記3箇所のみ
- 権限は個人単位ではなく「Googleグループ」単位で付与し、役員交代時の更新を簡略化する。

## ⑤：データ移行計画（案）

1. 現状の保管場所（PC・USB・共有サービス等）を棚卸しする
2. 移行優先順位：マニュアル → 会計 → 編集（サムライラジオ・ライブ映像） → 写真 → デザイン
3. 移行時は⑥のファイル命名規則に統一
4. 移行済みデータの旧保管場所には「移行済み」の目印をつける

※①②が完了しドライブが使える状態になってから着手。

## ⑥：運用ルール（ドラフト）

- ファイル名：`日付_内容_版数`（例：20260728_総会資料_v1）
- 保存場所に迷ったら「00_運営/未分類」に一旦保存し、後で管理者が整理
- 個人判断でのファイル削除は禁止。月1回、管理者が確認のうえ整理
- 新規フォルダ作成は管理者に相談してから行う

2. 旧役員の権限削除手順

   - 代替わり時にパスワードを変更し、紙も書き換える
4. データ管理ルールの説明・周知方法
