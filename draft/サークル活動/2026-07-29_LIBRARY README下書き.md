# 📌 はじめにお読みください（P-RITTS_LIBRARY 利用ガイド）

このフォルダは、P-RITTSの活動データ（動画・写真・マニュアル・広報素材など）をみんなで一元管理するための共有ドライブです。

## 使うときのお約束

- このリンクを知っている人は誰でも閲覧・編集・アップロードができます
- このリンクは部内の連絡（LINE等）以外では絶対に共有しないでください（SNS投稿や外部への転載はNG）
- ファイルやフォルダの削除は慎重に。月1回、役員が整理・確認しています

## フォルダの中身

- **00_マニュアル**：スタッフハンドブック／演者ハンドブック
- **01_広報**：年度ごとのチラシ・SNS投稿素材など
- **02_編集**：侍ラジオ（第N回ごと）、ライブ映像（年度→月ライブごとに撮影素材／完成データ／サムネ）
- **03_写真**：年度→イベントごとの写真
- **04_デザイン**：ロゴ・素材、ポスター、案件ごとのデザインデータ
- **05_アーカイブ**：現在は用途未定（保留中）
- **06_運営情報**：総会資料、会計報告（役員が定期的に更新する会計のスナップショットです。詳しい会計の元データは役員限定の別フォルダで管理しています）
- **未分類**：どこに入れるか迷ったら、とりあえずここでOK！

## 手持ちのデータ、アップロードお願いします！

これまでバラバラに個人のPCやUSBで保管されていた動画・写真・マニュアル・デザインデータなどを、このドライブに集めたいと思っています。ご協力よろしくお願いします！

- 該当する年度・イベントのフォルダが見つかれば、そこに入れてください
- 該当フォルダが無い／新しく作りたい場合は、役員に一声かけてください（新規フォルダは役員が作成します）
- 分類に迷ったら「未分類」フォルダに入れてもらえればOK。あとで整理します
- ファイル名は「日付_内容」など、後で見てわかる名前にしてもらえると助かります（例：`20260728_ポスター案_v1`）
