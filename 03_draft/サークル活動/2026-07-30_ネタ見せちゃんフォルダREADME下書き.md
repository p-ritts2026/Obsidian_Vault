# 📌 04_ネタ見せちゃん フォルダの使い方

このフォルダは、ネタ見せ時に使う「ネタ見せちゃんフォーム」で集めた感想・アドバイスの回答データを保管する場所です。

## ① ツールにアクセスする

- 「ネタ見せちゃん フォーム作成」ツール（Google Apps Script）のURL：
  `https://script.google.com/macros/s/AKfycbzyzgwY81515pKpPxd6NZ3SclLwAWYRZUxrlsSNJa5l0C4L2amsL8ezTWBkRmq8ElTzXQ/exec`
- Googleアカウントを持っていれば誰でも開けます（要ログイン）
- **必ずSafariやChromeなど普通のブラウザで開いてください**（LINEやInstagramのアプリ内ブラウザで開くとログインできません）

## ② フォームを作る（具体的な手順）

1. 上記URLを開く
   - 開催日欄には今日の日付が自動で入ります（変更もできます）
   - 説明文欄も、開催日を入れると「○月ライブのネタ見せ」の○月部分が自動で**開催日の翌月**に変わります（自分で書き換えた場合はそのまま残ります）
2. 出演者リストを入れます。やりやすい方法でOK、3通りあります
   - **1組ずつ入力**：「＋1組追加」で行を増やし、YouTubeリンク欄にリンクを貼ると名前（動画タイトル）が自動で入ります
   - **複数リンクをまとめて貼り付け**：「複数のリンクを一括で貼り付け」を開き、YouTubeリンクを1行に1つずつ貼って「リストに反映」を押す
   - **再生リスト（プレイリスト）からまとめて取り込み**：「再生リストから一括取り込み」を開き、YouTubeの再生リストURLを貼って「再生リストを読み込む」を押すと、中の動画が全部まとめて出演者リストに追加されます（一番手間が少ない方法です）
   - どの方法でも、自動で入った名前は間違っていたら直接書き換えられます
3. 「フォームを作成」を押す
4. 完成すると、
   - 「回答用リンクを開く」「編集する」ボタンが表示される
   - フォームは自動でGoogle Driveの「ネタ見せちゃん」フォルダに保存される
   - **グループLINE用の告知文**（【フォーム】【再生リスト】のリンク付き）が自動で組み立てられて表示されるので、「コピー」ボタンを押してそのままLINEに貼り付けられる
5. できたフォームのURLを、ライブの参加者・観客に共有して回答を集めてください

## ③ 回答をこのフォルダに保存する

1. Googleフォームの「回答」タブを開く
2. 緑のスプレッドシートアイコン（回答をスプレッドシートにリンク）をクリックし、新しいスプレッドシートを作成
3. できたスプレッドシートの共有設定を**「閲覧者」**に変更する
   - 感想・アドバイスのデータは、誰かが誤って編集・削除してしまわないよう、閲覧のみにしています
4. そのスプレッドシートを、このフォルダ内の「〇〇年度」フォルダに移動する
5. ファイル名は「〇月〇日 ネタ見せちゃん（回答）」の形式で統一してください（例：`7 24 ネタ見せちゃん（回答）.gsheet`）

## 使うときの注意事項

- **複数のGoogleアカウントに同時ログインした状態だとツールが開けないことがあります**。うまく開けない・「ファイルを開くことができません」と出る場合は、他のGoogleアカウントから一旦ログアウトしてから該当アカウント1つだけでログインし直すか、シークレットウィンドウ（プライベートブラウズ）で開いてください
- 初めて使うときや久しぶりに使うときは、「このアプリにはDriveへのアクセス権限が必要です」といった確認画面が出ることがあります。その場合は内容を確認して「許可」を押してください
- このツールは、作成したフォームをツール実行者自身のGoogleアカウントの**マイドライブ内**に自動で「ネタ見せちゃん」フォルダを作って保存する機能を持っています。**この自動フォルダはP-RITTS_LIBRARYの中には作られません**。そのため、フォームや回答データは今まで通り手動でこの`04_ネタ見せちゃん`フォルダに移動・保存してください
- ツールの中身（コード）を修正する必要がある場合は、役員（幹部）に相談してください
