# ①プロダクト・サービスデザイン

## 問題1：用語説明（3〜5文の短答版、5項目とも練習）

**推奨選択：(b)ダークパターン＋(e)MAYA理論**（記述の密度を作りやすく、他の受験者と差がつきやすい）

**(a) XR**
VR（仮想現実）・AR（拡張現実）・MR（複合現実）を包括する総称で、現実空間と仮想空間を融合させる技術群を指す。VRは視界を仮想空間に完全に置き換え、ARは現実空間に情報を重畳し、MRは現実と仮想の要素が相互に影響し合う点でそれぞれ異なる。近年はデバイスの多様化により、この3つの境界は技術的に曖昧になりつつある。

**(b) ダークパターン、ディセプティブデザイン ★推奨**
ユーザーの利益よりも事業者の利益を優先し、意図しない行動を取らせるよう設計されたインターフェース手法の総称である。解約手続きを意図的に複雑にする、初期設定で不要なオプションに同意させておくといった手口が代表例である。認知バイアスや注意力の限界を悪用する点に特徴があり、短期的な数値改善と引き換えに長期的な顧客の信頼を損なう構造的な問題をはらんでいる。近年は呼称としてより中立的な「ディセプティブデザイン」への置き換えも進んでいる。

**(c) デジタルツイン**
現実の製品・設備・都市などの状態をセンサで取得し、仮想空間上にリアルタイムで再現・同期させる技術である。単なる3Dモデルと異なり、現実とのデータ的な双方向性を持つ点が本質であり、これによりシミュレーションによる将来予測や異常の早期検知が可能になる。製造業の生産ライン管理や都市計画のシミュレーションに応用が広がっている。

**(d) SaaS**
Software as a Serviceの略で、ソフトウェアを端末にインストールせず、インターネット経由でブラウザ等から利用する提供形態である。利用者は常に最新版を使用でき、初期投資を抑えられる一方、事業者側は解約率（チャーン）の管理が収益の生命線となる。Google WorkspaceやSlackが代表例である。

**(e) MAYA理論 ★推奨**
アメリカの工業デザイナー、レイモンド・ローウィが提唱した設計原則で、Most Advanced Yet Acceptable（最も先進的でありながら、なお受容される）の頭文字を取ったものである。人は新しさに惹かれる一方、見慣れないものには不安を抱くという相反する心理を持つため、優れたデザインは市場が受け入れられる限界まで新しさを押し進めた地点に存在するとする考え方である。前衛的すぎれば拒絶され、保守的すぎれば陳腐化するため、両者の均衡点を見極めることが設計の鍵となる。初期の自動車が馬車の形を残していた例が典型とされる。

> **【較正メモ】** 公式解答例の分量とほぼ同等（4〜5文、200字前後）に合わせた。参考資料側の同項目はこの倍以上あるが、本番はこの分量が基本形。時間が余れば1文だけ具体例を足す。

## 問題2：サービス3分類法による新サービス創造（短縮版）

※公式解答例は非公開だったため、[[reference/大学院入試/2026-07-24_千葉大学大学院デザインコース入試対策資料の作成.md]]の「キッチン・オーケストレーション」案を短縮練習。

着目する行為「料理をする」。①自宅で調理家電を使う（Product oriented）②シェアキッチンを時間借りする（Function oriented）③デリバリーで完成品を受け取る（Result oriented）という3段階の間に、「結果は保証してほしいが、作る行為そのものは手放したくない」という空白がある。

提案する新サービスは、キッチンのセンサ（鍋底温度・まな板の重量・火力）が調理プロセスを認識し、「20時にこの味で完成していること」という結果を逆算して調理指示を提示する**結果保証型の行為支援サービス**である。所有は①、センシングと制御という機能提供は②、契約上保証される仕上がりは③の要素であり、いずれの分類にも収まらない第4の型として位置づけられる。単身・共働き世帯の食のスキル継承と食品ロス削減に寄与する。

# ③コミュニケーションデザイン

## 問題1：五感の応用・変形（2パターンで練習）

**パターンA：1事例を深く（公式解答例スタイルに近い）**

視覚を通じて触覚を喚起する事例として、原研哉が手がけた「HAPTIC」展が挙げられる。同展では、実際に触れていなくても、素材の質感や重さ、温度感が視覚的な情報（表面の陰影、色の濃淡、形状の緩急）だけから喚起されるようデザインされた展示物が並べられた。鑑賞者は過去の触覚的記憶と結びつけながら、展示越しであっても物理的な感覚を追体験する。この手法が生む感性的効果は、情報が言葉で説明されるのではなく感覚の記憶を通じて「発見」として受け取られる点にあり、強い納得感と印象の定着をもたらす。スクリーンを介したコミュニケーションが主流となった現在、触覚を視覚に翻訳するこうした試みは、デジタル環境下でも五感を総合的に設計する可能性を示している。

**パターンB：複数事例を広く（前回ノートの圧縮版）**

五感を応用・変形する事例は、感覚間の転写（クロスモーダル）として整理できる。第一に、自動車のドアを閉める音は聴覚から素材の密度や精度という触覚的な質を推論させ、「確かさ」の印象を生む。第二に、パッケージのエンボス加工や質感の対比は、視覚が触覚を予告することで「丁寧さ」の印象を先取りさせる。第三に、食器の色温度や店内BGMのテンポは味覚の評価そのものを変化させる。これらに共通する感性的効果は、直接的な言葉ではなく感覚的な手がかりから受け手自身が意味を補完する余地を作る点にあり、この「発見」の感覚が強い納得と記憶を伴う印象を生む。

> **【本番での選び方】** 出題趣旨は「多感覚的な刺激が感性や体験に与える影響を**具体的に**考察する力」を求めている。パターンAは具体性が高く1つの事例を掘り下げる分、視野の広さは示せない。パターンBは五感を横断する理解を示せるが1事例あたりの深さは浅くなる。**時間に余裕があればB、余裕がなければAを選ぶ**のが実戦的。

## 問題2：AI画像生成とグラフィックデザイナーの方向性（短縮版）

生成AIの普及により、ムードボードやラフ案の作成といった発想段階のコストはほぼゼロに近づき、デザイナーの価値は「案を作ること」から「大量の案から適切なものを選び、磨き上げること」へ移行しつつある。ただし生成された画像はあくまで素材であり、そこに文脈・意図・ユーザーとの関係性を与えるのは依然として人間の役割である。また類似性や著作権、学習データの偏りといった倫理的な論点についても、デザイナー自身が責任を持って判断する必要がある。したがってAIは仕事を奪う「代替」ではなく、案出しと検討の幅を広げる「拡張」の手段として位置づけるべきであり、今後のデザイナーには意図を明確に伝え、選択の理由を言語化する力が一層求められる。

# ⑦サステナブルデザイン

## 問題1：5択×3（正答の理由を短く確認）

**問1 正答：d（環境・経済・社会の3側面を統合的に考慮し、システム全体に影響する変化を目指す）**
→ トリプルボトムラインの統合とシステムレベルの変化という2点が原則の核心。a・b・c・eは「手段の一部の目的化」（寿命延長のみ、環境ラベル取得のみ、魅力優先、マーケティング戦略）であり、部分最適に矮小化した誤答。

**問2 正答：d（デザインは社会的に弱い立場にある人々のニーズに応えるべきである）**
→ パパネック『生きのびるためのデザイン』の核心的主張そのもの。a・b・c・eは経済成長優先／ブランド価値優先／美と機能の両立／高度技術唯一という、パパネックの思想と逆行または無関係な内容。

**問3 正答：c（「利用すること」に価値を置き「所有すること」からの転換を促す）**
→ PSS（Product Service System）の発想と一致。a・b・d・eは所有の重要性や価格・寿命短縮による循環という、転換の方向性と逆行する内容。

> **【解法原則の再確認】** 「〜のみ」「〜が最も重要」「〜によって保証される」という**限定・断定的な表現の選択肢はほぼ誤り**。統合的・システム的な視点を示す選択肢が正答になりやすい。

## 問題2：エコデザイン戦略モデル（8段階、新しい製品例で練習）

**8段階の名称（公式解答例より）**：①革新的・サービス機能再定義　②材料選定　③製造　④流通　⑤使用　⑥再使用　⑦リサイクル　⑧廃棄

**練習製品：モジュール式リペアラブル・バックパック**

① 革新的・サービス機能再定義：破れたら買い替える製品から、パーツ単位で修理・交換しながら使い続けられる製品へ再定義する。
② 材料選定：リサイクルナイロン生地と、分解しやすい単一素材の樹脂バックルを採用。
③ 製造：モジュールごとに独立して縫製し、接着剤を使わずファスナーで結合する工程を採用。部分不良品の交換を製造段階から容易にする。
④ 流通：フラットパッケージ化により輸送効率を向上。
⑤ 使用：底面・肩紐など摩耗しやすい部位を独立パーツ化し、交換によって製品寿命を延ばす。
⑥ 再使用：中古品を回収し、摩耗パーツのみ交換して再販するリファービッシュプログラムを実施。
⑦ リサイクル：単一素材設計により、生地とバックルを分別せず同一のリサイクルストリームに投入可能。
⑧ 廃棄：生分解性の低い部品を最小化し、廃棄時の環境負荷を抑える。

> **【スケッチ指示】** バックパックの図に①〜⑧の番号を吹き出しで配置し、各パーツ（肩紐・底面・バックル・生地）に矢印で対応させる。公式解答例（歯ブラシ・マイボトル）と同じ描き方。

# ④人間工学：出題趣旨を指針にした解答チェックリスト

出題趣旨の明言：「問題1, 問題2のいずれも**英語の小文から必要な情報を抽出し展開する能力**を問う」「新しい技術導入による**社会的影響について洞察する能力**」「測定時の**前提条件についての知識**」。この3点をそのままチェックリスト化する。

**問題1型（新技術の特徴＋社会実装の人間工学的課題）のチェックリスト**
- [ ] アブストラクトの中で「新規性を主張している箇所」を1文で特定できたか（"we show / the next generation / this study"の直後を探す）
- [ ] 特徴をハードウェア／計測プロトコル／データ解析法の3カテゴリに割り振ったか
- [ ] 課題は「実験室では成立するが日常利用では崩れる条件」から選んだか（装着の再現性・個人差・環境ノイズ・プライバシー・受容性）
- [ ] 方策は設計上／運用上／制度上の3層で書いたか

**問題2型（生理反応測定時の注意点）のチェックリスト**
- [ ] 論文中で言及されている交絡変数（食事、身体活動、薬理学的要因、日内変動、性周期等）を3点抽出したか
- [ ] それぞれについて「なぜ統制が必要か」の理由を、当該変数が測定対象にどう影響するかのメカニズムで説明したか
- [ ] 統制すること自体が被験者にとって「普段の習慣からの逸脱」という別の刺激になりうる、という限界点にも触れたか（Experimental Physiology論文が指摘する重要な留保）

> **【使い方】** 本番でこのチェックリストを答案構成メモ（2〜3分）の代わりに使う。埋まらない項目があれば、その論文のどこかにまだ拾えていない情報がある可能性が高い。
