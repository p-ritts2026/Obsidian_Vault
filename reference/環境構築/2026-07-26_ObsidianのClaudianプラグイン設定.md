## Claude  _(2026-07-26 05:26)_

*(ツール使用: web_search, web_fetch)*

GitHubの情報をもとに、YishenTu氏が開発している「Claudian」（Claude Code Obsidian連携プラグイン、⭐14.2k）の手順をまとめます。ただし注意点として、Obsidianのコミュニティプラグイン一覧には紛らわしいことに同名・類似名のプラグインが複数あります（"ClaudianIA"、"Claudian Plus"など）。今回目的の「Claude Codeをサイドバーで動かす」プラグインは、ストア上のスラッグが `realclaudian` になっている点に注意してください。

## 前提条件
- Obsidian v1.7.2以上（インストール済みとのことなので確認だけ）
- **Claude Code CLI** がPCにインストール済みで、ターミナルから `claude --version` で動作確認できること
  - 未インストールなら `npm install -g @anthropic-ai/claude-code` などで導入
- デスクトップ版のみ対応（macOS/Linux/Windows）。モバイル非対応

## インストール手順

### 方法A：コミュニティプラグインから（推奨）
1. Obsidianを開き、設定 → コミュニティプラグイン → 「閲覧」
2. 検索欄に「Claudian」と入力
3. 作者が **YishenTu** のもの（説明文に "Claude Code/Codex as an AI collaborator" とあるもの）を選んでインストール
4. インストール後、コミュニティプラグイン一覧で有効化

もし検索で見つけにくい・別のプラグインと混同しそうな場合は、直接このページからインストールできます：
https://obsidian.md/plugins?id=realclaudian

### 方法B：GitHub Releaseから手動インストール
1. https://github.com/YishenTu/claudian/releases/latest から `main.js`・`manifest.json`・`styles.css` をダウンロード
2. Vault内に以下のフォルダを作成
   ```
   /path/to/vault/.obsidian/plugins/claudian/
   ```
3. ダウンロードした3ファイルをそのフォルダにコピー
4. Obsidian設定 → コミュニティプラグイン → 「Claudian」を有効化

## 有効化後の設定
1. リボンアイコンまたはコマンドパレットからチャットサイドバーを開く
2. プロバイダとして「Claude」を選択（Claude Code CLIまたはAPIキー/サブスクリプションが必要）
3. CLIパスは基本的に自動検出されるはずですが、`spawn claude ENOENT` などのエラーが出た場合：
   - 設定は空欄のままにして自動検出に任せる
   - それでもダメならターミナルで `which claude`（Win: `where.exe claude`）を実行し、そのパスを 設定 → 詳細設定 → Claude CLI path に手入力
   - nvm/fnm/volta等のNodeバージョンマネージャ使用時は要注意（GUIアプリがNode.jsを見つけられないことがある）

## 主な機能（連携後にできること）
- ノート編集中にインライン編集（差分プレビュー付き）
- `@` でVault内ファイルやMCPサーバーをメンション
- `/` や `$` でスラッシュコマンド・Skills呼び出し
- `Shift+Tab` でPlan Mode（実装前に計画を提示・承認)
- ファイルの読み書き・検索・bash実行など、Vaultをそのままagentの作業ディレクトリとして扱える

設定データはVault内の `.claudian/`、Claude関連ファイルは `.claude/` に保存され、会話履歴は `~/.claude/projects/` に残ります。

うまく動かない場合は、まず `claude` コマンドがターミナルで正常に動くかを再確認するとトラブルシューティングが早いです。何かエラーが出たら教えてください。

```batch
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

2. ブラウザが自動で開き、Claude（Pro / Max / Team / Enterpriseいずれかのアカウント、または API利用の場合はConsoleアカウント）でログイン
   - ※無料のClaude.aiプランではClaude Codeは使えません
3. ログインが完了すればターミナル内で対話セッションが始まります

## この後の流れ

2. その状態で、前回案内した **Claudian プラグイン** をObsidianにインストール・有効化
3. Claudianの設定でプロバイダを「Claude」にすれば、自動的にCLIを検出してくれるはずです

## Claude  _(2026-07-26 05:34)_

*(ツール使用: web_search)*

原因はほぼ確実に **PATH（パスが通っていない）** です。ネイティブインストーラーは `%USERPROFILE%\.local\bin`（例：`C:\Users\こはく\.local\bin`）にインストールしますが、このフォルダがまだPATHに登録されていないため、`claude` コマンドが見つからない状態です。

## 確認方法
まず、本当にインストールされているか確認しましょう。PowerShellで：
```powershell
Test-Path "$env:USERPROFILE\.local\bin\claude.exe"
```
- `True` と出れば → インストール自体は成功していて、PATHの問題です（下の対処法へ）
- `False` と出れば → インストール自体が失敗しています（一番下の「再インストール」へ）

## 対処法（PATHが通っていない場合）

### 方法1：PowerShellでサクッと直す
```powershell
[Environment]::SetEnvironmentVariable("PATH", "$env:PATH;$env:USERPROFILE\.local\bin", [EnvironmentVariableTarget]::User)
```
実行後、**PowerShellのウィンドウを完全に閉じて、新しく開き直してから**：
```powershell
claude --version
```

### 方法2：GUIで確認・修正（方法1がうまくいかない場合）
1. `Win + R` → `sysdm.cpl` と入力してEnter
2. 「詳細設定」タブ → 「環境変数」ボタン
3. 上段の「ユーザー環境変数」で `Path` を選択 → 「編集」
4. 「新規」をクリックして以下を追加：
   ```
   C:\Users\あなたのユーザー名\.local\bin
   ```
5. すべてOKで閉じる
6. **開いているPowerShellをすべて閉じて**、新しく開き直す
7. `claude --version` で再確認

## それでもダメな場合（再インストール）
インストール自体が中途半端だった可能性があるので、もう一度インストーラーを実行してみてください：
```powershell
irm https://claude.ai/install.ps1 | iex
```
実行時に「Claude Code successfully installed!」のようなメッセージがちゃんと表示されているか確認してください。エラーメッセージが途中で出ていた場合はそれを教えてください。

Claude Desktop/claude.aiでの会話履歴をObsidianのVaultに移すことは可能です。方法はいくつかあり、目的（全部残したいか、大事な会話だけ厳選したいか）によって向き不向きが変わります。

## 方法1：公式の一括エクスポート機能を使う（全履歴が欲しい場合）

1. Claude Desktopアプリ（またはclaude.ai）を開く
2. 左下の自分のアイコン/イニシャルをクリック → 「設定 (Settings)」
3. 「プライバシー (Privacy)」セクションへ
4. 「データをエクスポート (Export data)」ボタンをクリック
5. 数分〜数時間後、登録メールアドレスにダウンロードリンクが届く（**24時間で失効するので早めにダウンロード**）
6. ZIPファイルがダウンロードされ、中に会話履歴が **JSON形式** で入っている

### 注意点
JSON形式なので、そのままだと人間には読みづらい生データです。ここからObsidian用のMarkdownノートに変換する一手間が必要になります。

## この変換作業、実はClaude Code自身にやらせるのが一番早いです

ダウンロードしたZIPを展開して、そのフォルダをVault内（例：`inbox/claude_export/`）に置いた上で、Claudianのチャットにこう頼めます：
```
inbox/claude_export/ にあるJSONファイルを読んで、会話ごとに読みやすいMarkdownノートに変換してください。
ファイル名は日付＋会話タイトルにしてください。
```
Claude Codeはbashやファイル操作ができるので、JSONをパースしてMarkdownファイル群を生成する、という作業を代行させられます。YOLOモードがオフなら、実行前に確認が来るはずです。

## 方法2：個別の会話だけを手動でコピー（厳選したい場合）
全部ではなく「これは残したい」という会話だけ選ぶなら：
1. 残したい会話を開く
2. `Ctrl+A` で全選択 → `Ctrl+C` でコピー
3. Obsidianで新規ノートを作成し、貼り付け・整形

数が少ないなら、こちらの方が手っ取り早いです。

## Claude  _(2026-07-26 06:41)_

では、全履歴を一括エクスポート→Markdown変換の流れで進めましょう。

## ステップ1：エクスポートを申請する
1. Claude Desktopアプリを開く
2. 左下の自分のアイコン/イニシャルをクリック → 「設定 (Settings)」
3. 「プライバシー (Privacy)」セクションへ移動
4. 「データをエクスポート (Export data)」ボタンをクリック
5. 登録メールアドレス宛にダウンロードリンクが届くのを待つ（数分〜数時間かかることがあります）

## ステップ2：ダウンロード＆展開
1. 届いたメールのリンクから ZIP ファイルをダウンロード（**24時間で失効するので早めに**）
2. ダウンロードしたZIPを展開する（Windowsなら右クリック→「すべて展開」）
3. 中身は `conversations.json` のようなファイルが入っているはずです

## ステップ3：Vault内に取り込む
1. Obsidianの本番Vault（`MyBrain`）のフォルダをエクスプローラーで開く
2. その中に新しいフォルダを作成：例えば `inbox/claude_export/`
3. 展開したJSONファイル一式をそのフォルダにコピー

## ステップ4：Claude Codeに変換を依頼
Obsidianを開き、Claudianのチャットパネルで以下のように依頼します：
```
inbox/claude_export/ 内のJSONファイルを読み込み、会話ごとに1つのMarkdownノートに変換してください。
- ファイル名：日付_会話タイトル.md の形式
- 保存先：inbox/claude_conversations/ フォルダを新規作成してそこに
- 内容：発言者（あなた/Claude）がわかる形で、時系列に整形してください
実行前に、まず数件だけ試して結果を見せてください。
```
**ポイント**：いきなり全部変換させず、「まず数件だけ試して」と指示するのがコツです。フォーマットの仕上がりを見てから、問題なければ「残り全部も同じ形式でお願いします」と続けられます。
