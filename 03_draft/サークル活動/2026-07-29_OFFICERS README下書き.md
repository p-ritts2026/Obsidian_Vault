# 📌 P-RITTS_OFFICERS 利用ガイド（役員限定）

ここは、運営・会計など役員だけが扱う資料を管理する場所です。

## アクセスについて

- ここは「役員Googleグループ」のメンバーだけがアクセスできます
- 権限管理用グループ：`pritts-officers@googlegroups.com`
- 新しく役員になった人：上記グループに追加してください
- 卒業・退任した役員：上記グループから削除してください
- 個人単位でファイルを共有することはせず、必ずグループ経由で管理してください

## フォルダの中身

- **00_運営**：総会資料、規約・引き継ぎ資料、名簿（部員名簿・連絡先。個人情報のためここに限定）
- **01_会計**：予算・決算資料（生データ）、領収書（生データ）

## サークル公式Googleアカウントについて

- アカウント：`pritts.official@gmail.com`
- パスワードは紙に控え、鍵のかかる場所（部室のキャビネット等）に保管しています
- 保管場所を知っているのは現役員のみです
- 二段階認証のバックアップコードも同様に安全な場所に保管しています

## 代替わり（引き継ぎ）のときにやること

1. 新役員を役員Googleグループに追加する
2. 旧役員を役員Googleグループから削除する
3. パスワードを変更し、紙の記録も書き換える
4. このフォルダの使い方・運用ルールを新役員に説明する

## 全員向けのデータについて

- 部員全体に公開しているデータは「P-RITTS_LIBRARY」（別フォルダ）にあります
- 会計の生データ（予算・決算の原本、領収書）や部員名簿など、公開しない情報は必ずこちらOFFICERSに保存してください
- LIBRARYとOFFICERSを間違えて保存しないよう注意してください

## 会計の透明性について（会計担当役員の仕事）

- 部員に会計状況を公開するため、月次や総会前などの節目で「予算・決算」を元にPDF等のスナップショットを作成してください
- 作成した報告書は、LIBRARY側の「00_運営情報／会計報告」フォルダに投稿してください
- 領収書や生データそのものはLIBRARYに置かないでください（個人情報が含まれる可能性があるため）

## 困ったときは

このシステムの構成や引き継ぎについて不明点があれば、前任の役員に確認してください。
